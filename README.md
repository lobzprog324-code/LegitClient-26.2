# Legit Client — Fabric

Client-side utility mod project with a module click GUI, FPS/coordinates HUD, keybinds, and JSON configuration.

## Controls
- Right Shift: open menu when no other screen is open
- H: toggle HUD
- Configuration: .minecraft/config/legitclient.json

Keystrokes and Notifications are placeholders for future implementation.

## Build
The GitHub Actions workflow builds with JDK 25 and uploads the JAR as an artifact. Check the Actions tab for the result.
