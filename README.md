# Sunnybrook Farm — Minecraft Java 26.2

A kid-friendly farm tycoon datapack with clickable NPC menus, exploration, item collection, and rewards. The `main` branch remains untouched; this version is in `farm-tycoon`.

## Install
1. Download this branch as ZIP using **Code → Download ZIP**.
2. Extract `sunnybrook_farm` into `.minecraft/saves/<world>/datapacks/`.
3. Open the world and run `/reload`.
4. In a clear area, run `/function farm:start` once to build the farm.

## Play
- Right-click **Mara** to start the first exploration quest. Harvest the crops and bring her one wheat seed, one carrot, and one potato. Use **Сдать находки** to turn them in.
- Right-click **Rook** to start the animal-supply quest. Break the hay bale near the barn and collect a carrot and wheat seed; bring all three supplies back and choose **Передать припасы**.
- Right-click **Pip** to start a delivery. Bring one bread and one potato, then choose **Сдать заказ**. Bread is a reward from completing Mara's first quest.
- Turn-ins check your inventory, consume the requested items, and pay rewards only once per quest.
- Pip also sells garden plots, a chicken coop, and a windmill. Rook offers a timed Harvest Festival and a small gift.

## Notes
This is a datapack, not a prebuilt world save. It builds around the player when `/function farm:start` is run. NPC interaction and commands still need an in-game test on Minecraft Java 26.2.
